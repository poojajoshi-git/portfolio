# Pooja Joshi — Senior Software Engineer Portfolio & Services

Production-ready, component-driven React application and backend services repository for **Pooja Joshi**, Senior Software Engineer with 5+ years of experience.

## 📁 Repository Structure
```text
pooja-portfolio-react/
├── public/
├── src/
│   ├── components/
│   │   ├── Header.jsx          # Navigation & Theme Toggle
│   │   ├── Hero.jsx            # Hero section with animated typing & live terminal preview
│   │   ├── Experience.jsx      # Professional timeline (Saama Technologies & Persistent Systems)
│   │   ├── Projects.jsx        # Featured projects with interactive modals
│   │   ├── Architecture.jsx    # Interactive system architecture playground
│   │   ├── Skills.jsx          # Categorized technical stack
│   │   ├── Terminal.jsx        # Functional interactive terminal emulator
│   │   ├── Contact.jsx         # Contact experience with clipboard copy feedback
│   │   └── Footer.jsx          # Copyright footer
│   ├── services/
│   │   └── pooja_engine.py     # FastAPI backend service & Airflow pipeline orchestrator
│   ├── App.jsx                 # Main application layout component
│   ├── main.jsx                # React root entry point
│   └── index.css               # Tailwind CSS base and scrollbar styles
├── package.json                # Dependencies and build scripts
├── tailwind.config.js          # Tailwind CSS custom design tokens
├── vite.config.js              # Vite bundler configuration
└── README.md                   # Repository documentation
```

## 🚀 Getting Started & Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
